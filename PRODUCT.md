# ER Atlas

<!-- impeccable:product-schema 1 -->

## Platform
web

## Product Purpose
Explore database tables, understand relationships, and prepare schema changes in a local workspace. The user's priority is clear, comfortable table reading and navigation.

## Operating Context
Arabic controls with English database and code identifiers. Existing vanilla JavaScript frontend and local Node server; preserve that stack and the existing workspace data.

## Capabilities and Constraints
- Tables, column definitions, relationships, diagram navigation, table inspection, and local change drafts.
- Tables can belong to several topics. Topic suggestions should use actual code usage, not names and foreign keys alone.
- Codex CLI and Claude Code can use their on-device sign-in without an API key.
- Existing draft review, undo/redo, SQL handoff, workspace switching, and saved layouts remain functional.
- Database edits are proposed as drafts; the visual redesign does not authorize direct database writes.

## Brand Commitments
Keep the ER Atlas name and focus on tables. The logo is the E+R table-block mark with the violet connection star (brand/logo-mark.svg), chosen by the user on 2026-10-10; it replaces the earlier connected-node mark. The identity is a matched light and dark pair of neutrals with one violet (the star) for the primary action, selection and focus. The user pinned an Excalidraw-style layout on 2026-10-13: a full-bleed canvas with floating pill chrome (menu and workspace top-start, one tool strip top-center, drafts and AI top-end, zoom and history bottom-start, counts and help bottom-end).
